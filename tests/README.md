# Стенды grnd_adm_tools.lua

Проверки гоняются без MoonLoader и без игры — обычным LuaJIT (`luajit` в PATH).
Каждый стенд сам вырезает нужный кусок из `grnd_adm_tools.lua` по якорям,
поэтому проверяется ровно тот код, который уходит в игру.

## Запуск

Из корня репозитория:

```
luajit tests/run_all.lua
```

Из каталога `tests`:

```
luajit run_all.lua
```

Скрипт можно указать явно, если он лежит в другом месте:

```
GRND_SCRIPT=/путь/grnd_adm_tools.lua luajit tests/run_all.lua
```

`run_all.lua` печатает `[ok]`/`[FAIL]` по каждому стенду, а в конце —
`=== все стенды пройдены ===`. Код выхода 0 — всё хорошо, 1 — есть провалы.

## Что проверяет каждый стенд

| Файл | Что проверяет |
|------|----------------|
| `run_all.lua` | синтаксис всего скрипта (`loadfile` целиком) + запуск трёх стендов ниже |
| `punauto_logic_test.lua` (41 проверка) | разбор строк чата: `Ник: текст`, `Ник крикнул: текст`, `(( Ник: текст ))`, метки времени и коды цвета, ник `Ник[12]`/`Ник(12)`, тег `[GOV]`; поиск триггера словом и точным совпадением; сборка команды (`{ID}`, `{ник}`, `{текст}`, `{триггер}`; без переменных команда уходит ровно как написана) |
| `punauto_module_test.lua` (272 проверки) | модуль автопилота целиком: вкладки и конфиг (`grnd_punauto.cfg`), выдача по всем трём видам строк, «Команда после», ОТСУТСТВИЕ задержек (v1.19.211: настройки «Пауза между выдачами» и «Повтор игроку» убраны — та же строка и тот же игрок выдают сразу, команда уходит напрямую, а не через очередь репорта с её 0.35 с на строку), предохранители (себя, администраторов, каналы чата, выключенная вкладка, пустая команда), режим проверки, `dryRun`, защита от двойного хука, отправка команды без переменных «как написано» и тумблер «подставлять ID без переменных»; автоскриншот после выдачи (имя файла без расширения — «.png» добавляет сам плагин, папка по умолчанию и своя, выключенный тумблер, запись в журнал; подтверждение появления ФАЙЛА, а не по вызову плагина: «сохранено» только когда кадр найден на диске, старая сборка плагина с «.png.png», честный провал с причиной, когда кадра нет; когда Screenshot.asi нет и проверить кадр нечем — в чат тоже уходит «не сохранён»); свой кадр через D3D9 (v1.19.205): задачу ставит тик, кадр снимает хук кадра ImGui (setupRender — он есть всегда, в отличие от события onD3DPresent), файл проверяется ещё раз после сохранения, а если свой кадр не вышел — подхватывает плагин или F8; путь туда-обратно UTF-8 ↔ UTF-16 (русские папки), короткие однострочные причины в журнале, и ни один вход модуля не зовёт необъявленную функцию; кадры идут по одному и результат принимается только по номеру своей заявки (v1.19.211: раньше заявки перекрывались, и «не сохранён» уходило в чат при уже записанном файле), перед отказом папка проверяется ещё раз (файл находится даже при другом написании пути), тост короткий — «Скриншот сохранен»/«Скриншот не сохранён», подробности в журнале, а ошибку кадра тик не глушит молча (`PA.err`); типы методов D3D9 записаны правильно — «int(__stdcall*)(…)», иначе LuaJIT отвечает «invalid C type» и съёмка падает; PNG собирается самим скриптом (D3DXSaveSurfaceToFile отвечал D3DXERR_INVALIDDATA): сверяются эталонные CRC32/adler32, структура PNG и CRC каждого чанка, пиксели читаются с поддельной D3D-поверхности — BGRA, RGB, R5G6B5, обрезка кадра и «перевёрнутый» кадр с отрицательным pitch, плюс запись файла на диск); путь для кадров: пусто — папка рядом со скриптом, относительный путь — от папки игры (а не от «Документов»), полный путь — как указан, кавычки по краям снимаются, недоступная папка — честный отказ с причиной, два написания пути (UTF-8 и системная кодировка) для русских папок, и в лог MoonLoader про скриншот не пишется ни строки); отрисовка страницы «Наказания» → «Автопилот» с заглушкой ImGui (буферы полей, кнопки режима, тумблеры, «+»/крестик, вкладки, «Разобрать») и проверка, что при реальном размере карточки меню (1920x1080: 672x514) видно ОБЕ колонки — триггеры, команды, скриншот, проверку строки, параметры и ленту, — и ничего не уезжает ниже карточки |
| `chatlog_test.lua` (17 проверок) | журнал «Общий чат»: скрытые строки (ответ сервера на `/admins` фонового чекера «Админы в сети») в лог не пишутся; строки до спавна/во время авторизации — пишутся; дубль одной строки из двух хуков не задваивается; категории «Действия администрации» и «Репорты и ответы» |

## Если что-то упало

Стенд печатает `FAIL <имя> got=[...] exp=[...]`. Имя подсказывает место:
`shout.*` — разбор криков, `fire.*` — выдача, `shot.*` — автоскриншот,
`draw.*` — клики по странице «Автопилот», `drawfit.*` — помещается ли
страница в реальное окно меню (обе колонки без обрезки),
`mute.*`/`dup.*` — журнал.
`shot2.*` — поведение без Screenshot.asi, `self.*` — свой кадр (D3D9),
`nodelay.*` — задержек нет (вторая строка и повтор тому же игроку срабатывают),
`find.*`/`stale.*`/`slow.*` — кадр нашёлся в папке под другим именем, чужой
результат съёмки и «поздний» кадр (записался после срока — отчёт всё равно честный),

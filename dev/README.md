# dev — стенды проверки `grnd_adm_tools.lua`

Стенды не входят в игру: это отдельные проверки для разработки.
Нужен Python 3 и `lupa` (`pip install lupa`).

| Проверка | Команда |
|---|---|
| синтаксис файла | `python3 checklua.py ../grnd_adm_tools.lua` |
| панель МП целиком (настоящий модуль + заглушки ImGui): рисуется ли панель, ведут ли себя кнопки при наведении и нажатии, нет ли обращений к несуществующим глобальным именам | `python3 panel_harness.py ../grnd_adm_tools.lua /tmp/panel_harness.lua && python3 run_lua.py /tmp/panel_harness.lua` |
| полоса шаблонов («Быстрые ответы»): выравнивание по левому краю окна репорта и «приклейка» под его нижнюю кромку, ширина не больше окна репорта (лишние кнопки — новым рядом), рост вниз до края экрана (без строки-подсказки), ответ игроку штатной `/ans ID текст` (в `/n` — только когда ID не распознан) и закрытие окна репорта после отправки | `python3 picker_harness.py ../grnd_adm_tools.lua /tmp/picker_harness.lua && python3 run_lua.py /tmp/picker_harness.lua` |
| окно «Шаблоны быстрых ответов» (редактор шаблона): нет нижних строк «Переменные» и заметки при нажатии «Удалить», подтверждение показывает сама кнопка, сообщения уходят тостами, поле «Текст ответа» выше | `python3 settings_harness.py ../grnd_adm_tools.lua /tmp/settings_harness.lua && python3 run_lua.py /tmp/settings_harness.lua` |
| раздел «Репорт»: четыре под-вкладки («Инструменты», «Ответы на репорт», «Наказания», «Автопилот»), заготовки разделов помечены «в разработке» | проверяется в `source_check.py` |
| шаблоны наказаний («Репорт → Наказания»): редактор с селектором команды (/ban, /mute, /rmute), поля «Время»/«Причина» по команде, сохранение и чтение конфига, полоса в окне репорта по центру и ровно по кнопкам (без пустоты справа), порядок «сначала ответ игроку штатной /ans ID текст, затем наказание без /n», стрелки первой строки списка нажимаются, ответ игроку (боевой), защита от отсутствия ID | `python3 punish_harness.py ../grnd_adm_tools.lua /tmp/punish_harness.lua && python3 run_lua.py /tmp/punish_harness.lua` |
| статическая проверка исходника (кнопки видны без наведения, единое наведение, снятие стилей, «песочница» панели, `/mp diag`) | `python3 source_check.py ../grnd_adm_tools.lua` |

Стенд полосы шаблонов так же грузит модуль «Быстрые ответы» отдельным чанком и
проверяет: левый край полосы совпадает с левым краем окна репорта, полоса едет
за окном, ответ уходит штатной командой `/ans ID текст` (а `/n` — только
резервный путь, когда ID игрока не распознан), после отправки шаблона окно
репорта закрывается (в режиме «в поле ответа» — остаётся открытым, там ещё
правят текст).

Очередь репорта (`grndRepQueue`) в стендах наказаний повторена как в игре: и
ответ `/ans`, и команда наказания встают в одну очередь и уходят по одной строке
за кадр, поэтому проверка `ORDER` ловит регресс, когда наказание отправляют в
обход очереди и оно обгоняет ответ игроку.

Стенд панели специально грузит модуль МП **отдельным чанком**: в игре модуль не
видит локальных переменных файла, поэтому «голое» имя вроде `im` внутри него —
это обращение к несуществующей глобальной переменной. Именно такая ошибка
(`attempt to index a nil value (global 'im')`) появлялась при наведении курсора
на кнопку панели; стенд её ловит (`ГОЛОЕ ГЛОБАЛЬНОЕ ИМЯ`).
